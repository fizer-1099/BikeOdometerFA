# کیلومترشمار دوچرخه (نسخه اولیه)

اپلیکیشن اندروید Kotlin با رابط فارسی، نقشه OpenStreetMap، محاسبه مسافت GPS، سرعت، ثبت پس‌زمینه با اعلان، تاریخچه و خروجی CSV.

## ساخت APK از طریق GitHub Actions (بدون نیاز به کامپیوتر)
1. فایل ZIP را استخراج کن.
2. در GitHub یک مخزن جدید و خالی بساز.
3. فایل‌های داخل پوشه پروژه را با Git/Termux در ریشه مخزن قرار بده و push کن.
4. وارد زبانه **Actions** مخزن شو و اجرای **ساخت APK اندروید** را باز کن.
5. بعد از موفقیت، از بخش **Artifacts** فایل `BikeOdometerFA-debug-apk` را دریافت کن.
6. APK را روی گوشی نصب کن و مجوز مکان را بده.

## نکته‌های مهم
- نقشه برای بارگذاری کاشی‌ها به اینترنت نیاز دارد.
- برای کار با صفحه خاموش، اعلان دائمی و مجوز مکان لازم است. در تنظیمات گوشی، محدودیت باتری برنامه را در صورت نیاز بردار.
- این نسخه اولیه است؛ قبل از استفاده جدی، مسیر را در فضای باز آزمایش کن و مسافت را با GPS یا کیلومترشمار معتبر مقایسه کن.
- این پروژه در این محیط روی دستگاه اندرویدی اجرا نشده است؛ ساخت APK باید از GitHub Actions انجام شود.
